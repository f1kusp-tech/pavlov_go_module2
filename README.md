# pavlov_go_module2 - v4

Консольная система денежных переводов на Go с конкурентной обработкой транзакций и защитой баланса через sync.Mutex.

## Возможности

- Создание учётных записей и вход по ID.
- Пополнение и снятие средств с проверкой баланса.
- Переводы между пользователями через очередь транзакций.
- Обработка очереди 3 воркерами через канал и sync.WaitGroup.
- Атомарный перевод: списание и зачисление под блокировкой двух пользователей.
- Детерминированный порядок блокировок по ID — без дедлоков при встречных переводах.
- Деньги в копейках (int64), без float64 на границах.
- Отчёт по транзакциям в порядке добавления в очередь.
- Проверка вводимых сумм и обработка ошибок.

## Что нового относительно v3

- В User добавлен sync.Mutex — Deposit и Withdraw потокобезопасны.
- В PaymentSystem добавлен sync.RWMutex для защиты мапы пользователей.
- При переводе блокируются оба пользователя в порядке возрастания ID — это исключает дедлок.
- Баланс хранится в копейках (Money int64), парсинг и форматирование без float64.
- Очередь вынесена в отдельный тип TxQueue с приватными полями.
- Результат обработки возвращается через TxResult, отчёт идёт в порядке добавления.
