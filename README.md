# pavlov_go_module2 - v3

Консольная система денежных переводов на Go с конкурентной обработкой транзакций.

Возможности

    Создание учётных записей и вход по ID.
    Пополнение и снятие средств с проверкой баланса.
    Переводы между пользователями через очередь транзакций.
    Обработка очереди 3 воркерами через канал и sync.WaitGroup.
    Просмотр пользователей и баланса.
    Проверка вводимых сумм и обработка ошибок.

Ограничения v3

    Balance в float64 без мьютекса — возможна гонка данных (чинится в v4).
    Неуспешные транзакции после обработки не сохраняются.

Запуск

go run main.go

Проверка на data race (ожидаемо предупреждение — исправляется в v4)

go run -race main.go
