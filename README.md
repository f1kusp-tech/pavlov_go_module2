# pavlov_go_module2 - v2

Простое консольное банковское приложение на Go.
Возможности

    Создание учётных записей и вход по ID.
    Пополнение баланса и снятие средств с проверкой баланса.
    Переводы между пользователями через очередь транзакций.
    Обработка очереди транзакций по порядку.
    Просмотр списка пользователей и текущего баланса.
    Проверка вводимых сумм и обработка ошибок.

Запуск

go run main.go
